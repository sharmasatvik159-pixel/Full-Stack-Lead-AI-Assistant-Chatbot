# Video Walkthrough Recording Guide

## Quick Recording Instructions for Satvik Sharma:

1. **Option A: Loom (Recommended & Easiest)**
   - Visit [loom.com](https://www.loom.com) and record your screen + microphone.
   - Run both backend (`npm run dev` in `backend`) and frontend (`npm run dev` in `frontend`).
   - Follow `WALKTHROUGH_SCRIPT.md` to speak through the project.
   - Download the `.mp4` file or save the Loom link.

2. **Option B: Windows Built-in Screen Recorder (Xbox Game Bar)**
   - Press `Win + Alt + R` to start recording screen + mic.
   - Press `Win + Alt + R` again to stop.
   - The video is automatically saved in `C:\Users\Acer\Videos\Captures\`.
   - Copy the `.mp4` file into this folder (`05_Video_Walkthrough`).

3. **Google Drive Submission Check:**
   - Place your video (`Walkthrough_Satvik_Sharma.mp4`) or a text file with your Loom/Drive link in this folder.
   - Ensure the Google Drive folder access is set to: **"Anyone with the link – Viewer"**.
